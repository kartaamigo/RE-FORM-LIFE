# ИИ EVE: модели, внедрение и границы

## Три независимые части

EVE состоит из локального разбора команд, разговорной модели и речевых адаптеров. Vosk распознаёт речь; Gemini генерирует ответы и вызовы разрешённых инструментов; Silero/Qwen/SpeechKit озвучивают. Модель синтеза речи не выполняет роль модели рассуждения.

В исходниках нет подтверждённого обучения собственной LLM, fine-tuning Gemini, векторной базы RAG или отдельного сервера обученной EVE-модели. Имя EVE обозначает продуктовый слой над адаптерами и логикой приложения.

## Текущий Gemini

| Параметр | Значение в коде |
| --- | --- |
| Провайдер | Google Gemini API |
| REST | `https://generativelanguage.googleapis.com/v1beta/models/<model>:generateContent` |
| Значение по умолчанию | `gemini-flash-lite-latest` |
| Замена выведенного из использования имени | `gemini-2.5-flash-lite` → latest |
| Настройка | `GEMINI_MODEL`, настройка модели приложения |
| Ключ | `GEMINI_API_KEY`, fallback `GOOGLE_API_KEY` |
| Temperature | 0.6 |
| Ответ без инструментов | maxOutputTokens 320 |
| Ответ с инструментами | maxOutputTokens 1600 |
| Запрос к API | до 45 секунд с учётом оставшегося общего бюджета |
| Цикл | до 4 ответов модели, максимум 8 вызовов инструментов |
| Общий deadline | 60 секунд |

Это значения реализации, а не обещания доступности провайдера. Псевдоним latest может со временем указывать на другую версию. Описание «retired» основано на наборе `RETIRED_GEMINI_MODELS` в проекте; актуальный каталог Google в ходе сбора не запрашивался.

Ключ для frozen Windows также читается из пользовательского окружения реестра, если родительский процесс имеет устаревшее окружение. Значения ключей в документацию не включаются.

## Контекст и память

Передаются system instruction, сообщения беседы, отобранные сохранённые факты и контекст приложения. Сообщения преобразуются в роли user/model, соседние одинаковые роли объединяются. Обычный адаптер берёт последние 16 сообщений переданной истории; разные API получают историю из разных таблиц.

Harness сообщает локальную дату приложения, завтра и до 50 активных колонок. `relevant_memories` ранжирует факты по совпадению слов длиной от трёх символов: бюджет 3500 символов, до 20 фактов, каждый до 300 символов. Это текстовый отбор, без embeddings.

Пользовательские факты сохраняются явно через механизм памяти. Выключение personalization отключает передачу этих фактов в предусмотренном потоке. История команд, история отдельного чата и память — разные сущности; очистка одного списка не означает удаления всех остальных.

## Инструменты модели

| Инструмент | Возможность | Ограничение |
| --- | --- | --- |
| `list_tasks` | Читает задачи и ID | До 50 записей, offset до 10000, фильтры дат/query/scope/done |
| `list_habits` | Активные привычки и отметки на дату | До 50 привычек |
| `finance_summary` | Доходы, расходы, баланс, категории за месяц | RUB, суммы в копейках; до 50 групп категорий |
| `utility_payments` | Платежи, сроки, статусы | До 50; без номеров счетов и адресов, но с названиями счетов |
| `search_memories` | Ищет сохранённые факты | Использует доступную при включённой памяти выборку |
| `propose_task_changes` | Предлагает create/update задач | 1–20 изменений, только при allow_changes |

Инструментов удаления задач, платежей, переводов денег, управления терминалом, установки программ или фонового расписания у Gemini harness нет. Локальные команды приложения могут иметь отдельные возможности вне этого списка.

Аргументы проверяет приложение. Неизвестные свойства/инструменты отклоняются. Для update ID должен быть прочитан через `list_tasks` в текущем запросе; нельзя обновить случайный ID по догадке модели.

## Подтверждение изменений задач

1. Модель читает актуальные задачи.
2. Предлагает create/update с разрешёнными полями: text, task_date, start_time, scope, section, done.
3. Приложение проверяет поля и активную колонку, сохраняет пакет и снимки update-задач в SQLite.
4. Прежние pending-пакеты получают superseded.
5. Генерация прерывается через `ConfirmationRequired`; пользователю показывается точный список.
6. Подтверждение действует 600 секунд, восстанавливается после нового подключения.
7. `BEGIN IMMEDIATE` защищает применение: проверяется pending-статус, срок и совпадение записей со снимками.
8. Весь пакет применяется либо откатывается; повторное подтверждение отклоняется.

Пример: «Перенеси незавершённые задачи на завтра» → list_tasks → propose_task_changes → preview → подтверждение → запись. До подтверждения задачи не меняются. Изменённая после preview задача блокирует пакет, чтобы не затереть новые данные.

Это правило относится к модельному пакету. Простая локальная команда создания задачи использует свой обработчик; в продуктовой документации нельзя утверждать, что абсолютно каждое изменение через EVE ожидает карточку подтверждения.

## Собственные команды

Хранятся в `assistant_commands`. Поля: название, фраза, нормализованная уникальная фраза, шаблон, mode и enabled. Mode command использует локально проверяемый набор intent; prompt передаёт запрос Gemini.

Ограничения: название до 60 символов, фраза 2–80, шаблон до 500; имя «Эва» в начале фразы и зарезервированные подтверждения запрещены. Разрешён максимум один параметр `{text}`. Подстановка однократная, без выполнения Python/JS и рекурсивных макросов.

Импорт/экспорт JSON сопровождаются валидацией и атомарным импортом; точные ограничения формата — в `eve_commands.py` и [старом каталоге команд](../EVE_COMMANDS.md). Готовый набор — `docs/examples/eve-commands.json`. Команда «Старт дня» → «Покажи план на сегодня» не требует модельного вызова.

## Распознавание речи

- Vosk: `vosk-model-small-ru-0.22`, локальная русская STT, sounddevice/PCM; путь можно задать `EVE_VOSK_MODEL`.
- Браузерный путь: зависит от поддержки Web Speech и внешнего поведения браузера.
- SpeechKit: отдельный облачный STT через Yandex.
- Голосовые источники `local_voice`/`browser_voice` требуют wake word; без него сервер возвращает ignored.

В native-агенте есть ограниченные окна разговора после активации. Это управление голосовым сеансом, а не бесконечный автономный агент.

## Синтез речи и профили

| Профиль/адаптер | Модель | Назначение и статус |
| --- | --- | --- |
| personal | Silero Russian V5 / v5_ru | Локальный голос, default xenia; также kseniya, baya |
| commercial | Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign | Локальный голос по текстовому описанию |
| Образец Qwen | Qwen/Qwen3-TTS-12Hz-0.6B-Base | Дополнительный путь голоса по WAV-образцу |
| SpeechKit | Yandex, default voice alena | Облачная озвучка при заданных реквизитах |

`build-profiles/commercial.json` содержит оригинальные описания мягкого русского женского голоса и пути образцов. Наличие профиля не означает наличие WAV/весов на компьютере. В `eve_local.py` реализованы загрузка/кэш моделей, проверка аудио, обработка нехватки GPU-памяти и путь повторной генерации. История `6b534c1` фиксирует работу над GTX 1660; новые замеры здесь не проводились.

## Что отправляется наружу

Gemini получает текст, историю, выбранные факты и результаты вызванных инструментов. Поэтому локальные задачи/финансовые агрегаты тоже могут попасть в облачный контекст при соответствующем запросе. SpeechKit получает аудио или текст синтеза. Vosk и локальный TTS вычисляют на устройстве, но их модели предварительно нужно получить.

Запрос Gemini включает ключ в URL; такую строку нельзя публиковать в диагностике. Проверка документации не включала сетевой аудит логов. Фактические ранее выполненные тесты и ограничения — в [EVIDENCE](EVIDENCE.md).
