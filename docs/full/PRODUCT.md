# Продукт и внедрённые возможности

## Название и идея

Продукт называется **RE:FORM LIFE**, ассистент — **EVE / Эва**. Это локальное настольное пространство для ежедневных планов, привычек, финансов и бытового учёта. Формулировка из README: «Маленькие шаги приводят к большим результатам». Интерфейс русскоязычный; основная аудитория по характеру реализации — индивидуальный пользователь.

Текущая реализация использует Flask внутри pywebview. Код не содержит законченной системы командного взаимодействия пользователей, облачной синхронизации между устройствами или полноценного многопользовательского аккаунта. Прототип нельзя описывать как готовый облачный сервис.

## Разделы

| Экран | Реализованная область | Источники |
| --- | --- | --- |
| Неделя | Задачи по дням, время начала, выполнение, цель недели, заметки и настроение | `templates/week.html`, обработчики tasks/goals/notes/mood |
| Задачи | Отдельный scope задач, пользовательские разделы/категории, представление доски | `templates/tasks.html`, `sections`, `tasks.scope` |
| Месяц | Календарь, поиск, категории, приоритеты и прогресс, список просроченных задач | `templates/month.html`, month priorities, notifications |
| Финансы | Доходы/расходы, категории, накопления, операции и месячные планы | `templates/finance.html`, transactions/savings |
| Коммуналка | Несколько счетов, услуги, тарифы, показания, передача показаний, начисления и оплата | `templates/utilities.html`, utility API |
| Привычки | Привычки, периодичность, расписание и ежедневные отметки | `templates/habits.html`, habits/habit entries |
| EVE | Единый чат и команды, голос, история, память, свои команды, инструменты Gemini | `templates/assistant.html`, модули `eve_*` |

Навигация — в `templates/base.html`. UI-логика большинства экранов — в `static/js/app.js`. Точные маршруты и поля хранения приведены в [API](API.md) и [DATABASE](DATABASE.md).

## Практические сценарии

1. Утром пользователь открывает неделю, добавляет задачу на дату и время, задаёт цель недели.
2. В течение дня отмечает выполнение, записывает заметку, доход или расход.
3. В коммуналке выбирает нужный счёт, вводит показания и отмечает передачу/оплату.
4. Вечером отмечает привычки и настроение.
5. Через EVE запрашивает план дня либо формулирует свободный вопрос.
6. Для сложного переноса задач Gemini читает актуальные записи, предлагает точный пакет, пользователь подтверждает.
7. Повторяющуюся фразу сохраняет как свою команду, например «Старт дня» → «Покажи план на сегодня».

Это сценарии использования существующих механизмов; каждый не проверялся заново на реальном desktop-окне при сборе документации.

## Возможности EVE для пользователя

Основные команды разбираются локально кодом. Ключ Gemini нужен для свободной беседы и запросов, передаваемых модели. При голосовом источнике требуется имя «Эва». Собственную фразу можно связать с основной командой либо с ИИ-запросом; эти режимы явно различаются в редакторе.

EVE может читать задачи, активные привычки, агрегаты финансов, коммунальные платежи и сохранённые факты через инструменты. Модельный инструмент изменения работает только с созданием/обновлением задач и требует подтверждения. Локальные основные команды имеют отдельный набор действий; их правила не следует переносить на все ИИ-запросы.

## Что не следует обещать

- Произвольные скрипты и терминальные команды через модель.
- Автономные фоновые напоминания, созданные Gemini: соответствующего инструмента harness нет.
- Изменение финансов и коммуналки инструментами Gemini: они дают чтение.
- Полностью офлайн-режим всех функций: Gemini и SpeechKit используют облако.
- Готовую мобильную версию или гарантию удобства на телефоне.
- Проверенную чистую установку, подписанный macOS-релиз или действующую общую лицензию проекта.

В коммунальном модуле есть собственные механизмы напоминаний; отсутствие инструментов фоновых напоминаний у модели не означает отсутствия любых уведомлений приложения.

## Планы, существующие отдельно от реализации

В прежнем [ROADMAP](../ROADMAP.md) предложены резервные копии, обзор дня, недельные итоги, миграции, адаптация к маленьким экранам и оформление прав. У этих предложений нет автоматически подтверждённого статуса внедрения. В текущем API нет общего законченного экспорта/восстановления всех пользовательских данных.
