# Запуск и обслуживание

## Windows: исходники

Исходная ориентировочная версия Python — 3.13, используемая в GitHub Actions. Прочие версии отдельно не подтверждены. Для нового окружения из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

Launcher запускает Flask только на `127.0.0.1`, выбирает свободный порт и открывает окно pywebview. Для pywebview на Windows может потребоваться доступный WebView2 runtime. Если окно не открывается, сначала проверить установку зависимостей и сообщения запуска.

Для просмотра интерфейса в браузере без окна:

```powershell
.\.venv\Scripts\python.exe -m flask --app app run --host 127.0.0.1 --port 5000
```

Открыть `http://127.0.0.1:5000`. Не включать debug для обычного использования. Прямой `python app.py` в текущем коде включает debug и предназначен для разработки. Приложение пока рассчитано на личный локальный запуск; публикация его API в сеть требует отдельной подготовки.

## macOS

Есть `requirements-macos.txt`, `ReFormLife.mac.spec` и задание сборки macOS. Для исходников используются зависимости из `requirements-macos.txt`. Полный запуск на macOS в этом сеансе не проверен; Windows-действия ассистента нельзя считать автоматически переносимыми.

## Где лежат данные

| Режим | Путь |
| --- | --- |
| Исходники | `instance/reform_life.sqlite3` |
| Упакованная версия | Обычно `%LOCALAPPDATA%\RE-FORM LIFE\reform_life.sqlite3`, с запасным вариантом через `APPDATA` |
| Пользовательский каталог | `REFORM_LIFE_DATA_DIR` |
| Полный путь базы | `REFORM_LIFE_DB` — имеет приоритет |

Для ручной резервной копии полностью закрыть приложение и голосовой агент, затем скопировать файл базы в личную папку. Не добавлять его в репозиторий: внутри могут быть задачи, расходы, адреса, история и память EVE. Встроенный пользовательский экспорт/восстановление предлагается в плане развития.

## EVE

- Основные локальные команды не требуют ключа Gemini.
- Для свободного разговора задать `GEMINI_API_KEY` в окружении процесса и перезапустить приложение.
- Локальное распознавание использует Vosk и микрофон; модель `vosk-model-small-ru-0.22` отслеживается в репозитории.
- Локальная нейросетевая озвучка требует отдельной установки TTS-зависимостей и моделей.
- SpeechKit требует `YANDEX_SPEECHKIT_API_KEY` и `YANDEX_SPEECHKIT_FOLDER_ID`, а также выбора провайдера в настройках.
- Доступ к внешним сервисам и их стоимость зависят от условий провайдера.

Подробные модели, профили и настройки: [EVE_LOCAL_SETUP.md](../EVE_LOCAL_SETUP.md). Не вставлять реальные ключи в документы или коммиты.

## Существующие тесты

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -q
```

Проверки создают временную базу. Интеграции во многих сценариях подменяются, поэтому тесты не заменяют ручную проверку речи и готовой сборки. Если среда запрещает работу с системным временным каталогом, это ограничение окружения следует отделить от ошибки приложения.

## Сборки

`.github/workflows/release-portable.yml` запускается для тегов `v*` или вручную. Использует PyInstaller и собирает версии Windows/macOS. При добавлении документации в `main` релиз автоматически не создаётся.

Для Windows `ReFormLife.spec` проверяет выбранный голосовой профиль, зависимости, наличие модели и лицензии. Простого базового `requirements.txt` для полной голосовой сборки недостаточно. Порядок настройки описан в [EVE_LOCAL_SETUP.md](../EVE_LOCAL_SETUP.md).

Сборки private-репозитория доступны с учётом прав GitHub. Репозиторий с исходниками и скачиваемый дистрибутив — разные результаты; в этом обновлении оформлены и отправлены исходники с документацией, новая сборка приложения не создавалась.
