# Протокол проверки

## Harness EVE — 10 октября 2026 года

После добавления Python harness выполнено:

```text
python -m unittest discover -s tests -q
Ran 70 tests in 14.871s
OK

node --check static/js/app.js
```

Проверены модельный цикл, сохранение provider signatures, отклонение неизвестных
и некорректных вызовов, лимиты шагов/времени, чтение данных, отключение Gemini и
памяти, предложения задач, повторные и устаревшие подтверждения, отмена,
восстановление через новую DB connection, откат всего пакета при сбое SQLite,
неоднозначные команды и блокировка одновременно выполняемых модельных запросов.
Тесты выполнялись с разрешённым доступом к временным SQLite-файлам: ограниченная
среда Windows препятствует доступу к TemporaryDirectory.

Реальный Gemini API проверен на вымышленных задачах в отдельной базе в памяти.
Русский запрос на перенос незавершённых задач вызвал `list_tasks`, затем
`propose_task_changes`; harness вернул запрос подтверждения, исходная задача
осталась на прежней дате. Пользовательская база не использовалась в этой проверке.

Не проверялись новая переносимая сборка, реальный микрофон/озвучивание и полный
визуальный сценарий в desktop-окне. Работа конкретных свободных формулировок
зависит от модели; успешный smoke test не гарантирует понимание любого запроса.

## Автоматические тесты

```text
.venv/Scripts/python.exe -B -m unittest discover -s tests -q
Ran 46 tests in 67.513s
OK
```

Первый запуск в ограниченной среде завершился ошибками доступа к системной временной папке Windows. Повторный запуск с разрешённым доступом успешно выполнил все 46 тестов.

Окружение выдало сообщения об отсутствии SoX и flash-attn. Они не привели к провалу этого набора тестов; проверка реального звукового вывода и производительности моделей отдельно не выполнялась.
