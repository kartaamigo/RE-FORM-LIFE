# Основные и свои команды EVE

Добавлено **10 октября 2026 года**. Доступно в обновлённых исходниках; переносимая
EXE-сборка в рамках этой работы не пересобиралась.

## Основные команды

На странице EVE открой **«Основные и мои команды»** или нажми **＋** возле
поля сообщения. Каталог содержит 15 примеров: планы, задачи, финансы,
коммуналка, память, браузер, папки, поиск и запросы к ИИ. Нажатие на пример
только подставляет его в поле сообщения; отправка выполняется отдельной кнопкой.
Для голосового ввода добавь имя: «Эва, покажи план на сегодня».

## Как добавить свою фразу

1. Заполни название и свою фразу, например «Утренний план» и «Старт дня».
2. Выбери **«Основная команда · без ИИ»**.
3. В поле действия введи «покажи план на сегодня» и сохрани.
4. Напиши «Старт дня» или скажи «Эва, старт дня».

Кнопка **«Сделать своей»** возле примера подставляет исходное действие;
остаётся придумать фразу. Свои команды сохраняются в SQLite и доступны после
перезапуска. Их можно редактировать, отключать и удалять.

## Команда с текстом

Используй один параметр `{text}` — он заменяется текстом после своей фразы:

| Поле | Значение |
| --- | --- |
| Моя фраза | Быстрое дело |
| Действие | добавь задачу {text} на завтра |
| Что сказать | Эва, быстрое дело купить молоко |
| Результат | Создание задачи «купить молоко» на завтра |

Параметр обязателен при вызове такого шаблона. Слова после фразы не должны
изменять тип действия. Замена выполняется один раз; команды не вызывают другие
свои команды рекурсивно. При совпадающих началах выбирается самая длинная фраза.

## Свой запрос к ИИ

Выбери **«Запрос к ИИ · нужна Gemini»**, например:

- Фраза: «Помощь с планом».
- Запрос: «Помоги спланировать завтра по моим задачам и привычкам».

Такой запрос проходит через harness EVE и использует его инструменты,
лимиты и подтверждения. Нужны включённая Gemini и настроенный API-ключ.
Расширенный запрос и используемые данные отправляются провайдеру так же, как
обычное сообщение EVE. Основная своя команда обрабатывается локальным парсером
и не переходит к Gemini при отсутствии подходящей задачи.

## Перенос и обмен

**«Экспорт моих команд»** скачивает файл `eve-commands.json` с версией формата 1.
**«Импорт команд»** добавляет команды из такого файла. Набор проверяется целиком:
если фраза уже существует или одна запись некорректна, ничего не импортируется.
Существующие команды не перезаписываются; при конфликте поменяй свою фразу
или фразу в импортируемом файле. Импорт сам по себе не выполняет действия.

[Готовый набор из трёх примеров](examples/eve-commands.json): «Старт дня»,
«Быстрое дело» и «Помощь с планом». Его можно импортировать на странице EVE.

Пределы: до 100 своих команд, фраза до 80 символов, название до 60, действие
и развёрнутая команда до 500, импортируемый файл до 128 КБ. Фразы основных
команд, подтверждения и остановки разговора зарезервированы. Произвольные
скрипты и команды терминала не являются типом пользовательского расширения.
Подтверждения исходных действий, например создания папки, сохраняются.

## Для интеграций

| Endpoint | Назначение |
| --- | --- |
| `GET /api/assistant/commands` | Каталог и свои команды |
| `POST /api/assistant/commands` | Создать свою команду |
| `PATCH /api/assistant/commands/<id>` | Изменить поля или включённость |
| `DELETE /api/assistant/commands/<id>` | Удалить свою команду |
| `GET /api/assistant/commands/export` | Выгрузить набор |
| `POST /api/assistant/commands/import` | Атомарно импортировать набор |

Запись: `name`, `phrase`, `template`, `mode` (`command` или `prompt`),
`enabled` (boolean). Формат набора: `{"version": 1, "commands": [...]}`.
Это расширение словаря EVE на существующих действиях и harness, а не загрузчик
исполняемых Python-плагинов.
